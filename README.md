# 수어 키보드 AI v3.0 (한·영 KSL/ASL & 한손·양손 42관절 통합 수어 키보드)

전면 카메라(`CameraX`)와 온디바이스 `MediaPipe Hand Landmarker`(`NumHands = 2`)를 결합하여:
1. **한손 수어**: 한국수어(KSL) 한글 지문자 24자(`ㄱ~ㅎ`, `ㅏ~ㅣ`) 및 미국수어(ASL) 알파벳 지문자 26자(`A~Z`, 동적 `J`/`Z` 궤적 포함)
2. **양손 공식 수어 단어 (42관절 동시 추적)**: 두 손의 수형·거리·상하 관계·움직임을 분석해 공식 한국수어(집, 학교, 병원, 약국, 도와주세요, 감사합니다, 만나다, 같다, 사랑합니다, 일하다, 더, 끝 등)와 ASL 양손 단어를 실시간 인식합니다.
